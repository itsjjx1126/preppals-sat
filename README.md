# PrepPals-SAT

PrepPals is a study-partner matching platform that connects high school
students preparing for the SAT. I founded it after my own SAT scores stalled
until a friend shared how he improved. It matches students with peers so
no one has to rely on luck to find a study partner.

## How it's built
- Front end: HTML, CSS, and JavaScript
- Backend and database: Supabase
- Hosting: Cloudflare Pages
- iOS version: the website is packaged as an iOS app with Despia and
  published on the App Store

## My role
I designed the product and features, wrote the code while learning, tested it,
and led a team of about 20 students across several schools who run and
promote it.

## Tools and help (full disclosure)
- I first built a version with Base44 (an AI app builder), but Apple rejected
  it, so I abandoned that version and rebuilt the app myself. None of the
  Base44 code is in this repository.
- I used Claude, an AI assistant, as a bug checker. I pasted my own code into
  it, asked whether it would run correctly, and then changed the code myself.
- Despia packages my website as an iOS app for the App Store. Despia's CEO
  also gave me guidance on errors such as App Store rejection and privacy
  policy requirements.
